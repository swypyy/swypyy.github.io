# Swypyy's Website

A personal portfolio and learning site built with GitHub Pages and Jekyll, featuring projects, writing, and web experiments.

🌐 **Visit the site:** [swypyy.github.io](https://swypyy.github.io/)

## About

This repository contains the source for my personal website. It brings together my projects and blog, while giving me a place to practice and improve my web development skills.

## What's here

- Personal homepage and project showcase
- Blog posts powered by Jekyll
- Pages for my web projects, including [Anonymous Chat](https://swypyy.github.io/anonymous-chat.html) and [Anonymous Drop](https://swypyy.github.io/blog.html)
- Static HTML, CSS, and JavaScript pages

## Built with

- HTML, CSS, and JavaScript
- Jekyll and Liquid
- GitHub Pages

## Run locally

The site is hosted with GitHub Pages. To preview it locally, install Ruby and Bundler, then run:

```bash
git clone https://github.com/swypyy/swypyy.github.io.git
cd swypyy.github.io
bundle install
bundle exec jekyll serve
```

Open [http://localhost:4000](http://localhost:4000) in your browser. The repository's Jekyll configuration is in [`_config.yml`](./_config.yml).
